THE PATCH LAG PROBLEM

jellyfin-web has been exposed to a yargs-parser vulnerability for 2,090 days — with a fix available the entire time. Every other scanner reported this. None told you it had been sitting there for nearly 6 years.

THE OWNERSHIP PROBLEM

When dompurify CVE drops, who do you Slack? DriftWatch maps GitHub code search × commit history to your dependency list, so the ticket already names the engineer who imported it.

THE PRE-CVE PROBLEM

Maintainers deprecate versions with "fixed a security issue" notes before CVEs get filed. DriftWatch reads those deprecation messages from deps.dev — you get the warning days or weeks before any scanner.
